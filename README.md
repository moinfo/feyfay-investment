# Feyfay — Creation, Innovation & Entertainment

> The official website for **Feyfay Events**, a full-service event management company specializing in entertainment and empowerment events across the region.

---

## About

Feyfay is dedicated to organizing world-class events that inspire, entertain, and empower communities. From talent searches to youth conferences, we bring people together through unforgettable experiences.

---

## What We Do

### Entertainment Events
- **Talent Search** — Discovering and showcasing emerging talent
- **Shows & Concerts** — Live performances and music events
- **Awards Ceremonies** — Celebrating excellence and achievement
- **Sports Bonanza** — Thrilling sports competitions and tournaments

### Empowerment Events
- **Youth Seminars** — Inspiring the next generation of leaders
- **Women Conferences** — Empowering women across all sectors
- **Community Gatherings** — Bringing special groups and organizations together

---

## Tech Stack

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React

---

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

Open [http://localhost:3000](http://localhost:3000) to view the website.
